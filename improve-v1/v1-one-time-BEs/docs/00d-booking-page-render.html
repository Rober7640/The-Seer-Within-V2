Decided: Treatment B

B is the build target — plain direct-response

White ground, system sans, red headline, green CTA, dashed-border bump. This is what the source actually ran, and it is what the shared booking page component gets built as. A and C stay in this render as reference and as ready-made A/B challengers.

What B locks in for the build

Ground #FFFFFF · ink #111111 · headline #B3261E · CTA #16A34A · bump border #D97706 on #FFFBEB. Arial/Helvetica stack, no webfont — which also means the page has no font-loading dependency and renders instantly.

Cheap to revisit

One config-driven component serves all four offers, so swapping treatment later is a stylesheet change, not a rebuild. C is already written if you ever want to test it.

The gating decision is still open, and you can feel it here

All six boxes are required before the button enables. Try it at mobile width — six taps before a button lights up feels longer than it sounds. That friction is the commitment device working, or it's the thing costing you the sale.

The price still hides in the sixth checkbox

Kept in all three, because it's the source's structure and not an oversight: you agree to five things about the reading before money is mentioned, and by then agreeing is a habit.
