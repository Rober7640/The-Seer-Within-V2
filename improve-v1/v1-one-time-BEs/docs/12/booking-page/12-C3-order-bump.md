## Build notes

- **Short, like 11's.** A label and one line, above the total.
- **"The best twelve", not "the best one each month".** The operator's brief says "not just the best one each month". "Each month" is a date promise that 12-A may break, so the bump says "the best twelve".
- **Rule 1, adjacent.** It's more of what she's already buying, not a different thing.
- **Rule 3, the limit is the first line.** "My reading gives me twelve days" is true and says what the reading doesn't do, without saying it falls short.
- ⚠ **The code must keep it.** Every lucky day, by the same rule as her twelve, inside 2027. If 12-A moves her twelve to "the next twelve from the order", this page needs the same decision.
- **How it reaches her.** The last page of her PDF. T3 and T4 go to every buyer, so neither mentions it.
