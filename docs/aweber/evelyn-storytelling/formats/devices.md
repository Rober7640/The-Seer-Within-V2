# Devices — moves that work inside any format

From Matt Furey, *Tao of Email Copywriting* (PDF pages in brackets).

| Device | What it is | Use it? |
|---|---|---|
| **One laugh per email** (p.30) | *"Entertainment is more important than education… One laugh per email is good."* | ✅ Aim for one smile per email |
| **A punchy first line** (p.7) | *"Surgery sucks. Especially open heart surgery."* — short, blunt, emotional | ✅ |
| **Talk-write** (p.28–29) | Say it out loud, then type what you said; write at "six months of English" level | ✅ (our grade 3–5 rule) |
| **Coined words / name the readers** (p.31) | "Fure-cat", "the Furey Faithful" — readers start using them | 🧪 e.g. a name for Evelyn's readers — operator to decide |
| **Columbo P.S.** (p.53) | Seem to close, then a strong new point in the P.S. | ✅ |
| **Two options close** (p.50) | "Two ways to get the job done: 1… or 2…" | ✅ (our path A / path B) |
| **Tell them they aren't getting it all** (p.12) | Say plainly the details are in the paid part | ✅ ("that part isn't in this email") |
| **Sensory tease subject** (p.53) | "She licked the white creamy drops…" → it's a doughnut | ⚠ Only if tasteful for this list |
| **Quote as subject** (p.64) | Kipling's "6,000,000 reasons — not a single excuse", explained in the P.S. | 🧪 |
| **Higher authority** (p.55) | Share another trusted voice's view (Doug → Frank McKinney) | 🧪 |
| ⚠ **Name in every subject** (p.6, Mistake #1) | *"A strength over-extended becomes a weakness."* | We use name-first (proven on this list) — **watch open rates for wear** |
| ⛔ **Table of contents at the top** (p.6, Mistake #2) | Lists the email's contents first | Never |
| ⛔ **Over-teaching** (p.7, Mistake #4) | Satisfies her, so she doesn't need the chat | Never |
